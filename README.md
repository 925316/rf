# rf

### Auto-loads. No config, no hotkeys, no UI.

> [update for A39](https://store.steampowered.com/news/app/636480/view/689769594581157458)

Player weapons only:

- Projectile steering
- Ammo persistence
- Hold-to-auto

Settings hardcoded in `src/rf/settings.cs`.

Build: run `build.bat` → `Build\Release\rf.dll`. Put in `BepInEx\plugins\rf\`.

Use [x86](https://github.com/BepInEx/BepInEx/releases/download/v5.4.23.5/BepInEx_win_x86_5.4.23.5.zip) [BepInEx](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5)
